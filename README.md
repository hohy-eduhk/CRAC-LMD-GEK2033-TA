# CRAC-LMD-GEK2033-TA
Teaching assistant of the course GEK2033, for the two case studies.

**System Requirements**
Browser: Please use the latest version of Google Chrome, Microsoft Edge, or Brave, all of which support WebGPU.
Hardware: For the best performance, we recommend a computer with a dedicated graphics card or Apple Silicon (M1 / M2 / M3 / M4).
